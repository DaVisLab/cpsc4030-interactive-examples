Understanding search tasks

Learning goal

Learn to distinguish lookup, locate, browse, and explore by considering what the user knows about the target and where to find it before starting a task.

The dataset

200 real movies from the 1960s–2000s, with title, release year, genre, runtime, budget, worldwide revenue, and audience rating. Some runtimes and one rating are simulated; other figures are historical.

One task per page

Work through four tasks in a randomized order using the same movie dataset. Complete each task to unlock the next. On each page:

  1. Read the task and use the visualization to complete it.
  2. Then choose its search type. For “Something unexpected,” also briefly explain your reasoning.

Your first search-type answer earns up to one point per task. Finish all four to see your score and explanations.
